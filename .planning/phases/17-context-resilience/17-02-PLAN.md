<task type="auto">
  <name>Task 1: Create SessionStart hook</name>
  <files>.claude/get-motif/hooks/motif-session-start.js</files>
  <action>
Create `.claude/get-motif/hooks/motif-session-start.js` — a Node.js script that fires on SessionStart events (startup, resume, clear, compact) and injects Motif state into Claude's context.

**How it works:**
1. Determine project dir: `process.env.CLAUDE_PROJECT_DIR || process.cwd()`
2. Run `node {projectDir}/.claude/get-motif/scripts/motif-state.js read` via `require('child_process').execSync` to get state JSON
3. If state JSON has `error: "missing"` or `error: "corrupt"`:
   - Run `node {projectDir}/.claude/get-motif/scripts/motif-state.js recover` to attempt recovery
   - If recovery returns valid state, use it and set `recovered = true`
   - If recovery returns null/error, exit silently (not a Motif project)
4. If valid state exists (direct read or recovered):
   - Build context string: `[Motif State] Phase: {phase} | Vertical: {vertical} | Stack: {stack} | Screens: {screens_composed}/{screen_count} | Last: {last_command} ({last_outcome})`
   - If recovered, prefix with: `[Motif State RECOVERED from artifacts]`
   - Output the Claude Code SessionStart response format:
     ```json
     {
       "hookSpecificOutput": {
         "hookEventName": "SessionStart",
         "additionalContext": "<context string here>"
       }
     }
     ```
   - Use `console.log(JSON.stringify(...))` for output
5. If no valid state and no recovery possible, exit with code 0 silently (not a Motif project)

**Error handling:**
- Wrap everything in try/catch. Never crash — a crashed hook blocks Claude Code.
- If execSync throws, exit silently (motif-state.js not found = not a Motif project).
- All errors go to stderr only.

**Shebang:** `#!/usr/bin/env node` with `'use strict'`

**Note on bug #15174:** This hook's output will be silently dropped when the trigger is `compact`. This is acceptable — the CLAUDE.md rule and statusLine provide backup. Do NOT try to work around the bug in this script.
