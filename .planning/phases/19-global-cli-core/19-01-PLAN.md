     - Handle `--help` / `-h` / `help` subcommand: print a help message showing available commands (`motif init`, `motif help`) and the legacy npx usage. Use `node:util styleText` for formatting (same pattern as install.js line 27-46)
     - Handle `--version` / `-v`: read version from `../package.json` and print it
  </action>
