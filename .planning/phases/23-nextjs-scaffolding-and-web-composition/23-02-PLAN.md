**Output structure — globals.css with three layers:**

```css
@import "tailwindcss";

/* === Layer 1: Motif Design Tokens (source of truth) === */
:root {
  /* Colors */
  --color-primary-50: #value;
  ...
  /* Surfaces */
  --surface-primary: #value;
  ...
  /* Text colors */
  --text-primary: #value;
  ...
  /* Borders */
  --border-primary: #value;
  ...
  /* Typography (sizes only, NOT font-family -- next/font handles that) */
  --text-xs: 0.75rem;
  ...
  /* Spacing */
  --space-1: 0.25rem;
  ...
  /* Radii */
  --radius-sm: 4px;
  ...
  /* Shadows */
  --shadow-sm: value;
  ...
  /* Transitions */
  --ease-default: value;
  --duration-fast: 150ms;
  ...
}

/* === Layer 2: shadcn/ui Semantic Mapping === */
:root {
  --background: var(--surface-primary);
  --foreground: var(--text-primary);
  --card: var(--surface-elevated);
  --card-foreground: var(--text-primary);
  --popover: var(--surface-elevated);
  --popover-foreground: var(--text-primary);
  --primary: var(--color-primary-500);
  --primary-foreground: var(--text-inverse);
  --secondary: var(--surface-tertiary);
  --secondary-foreground: var(--text-primary);
  --muted: var(--surface-tertiary);
  --muted-foreground: var(--text-secondary);
  --accent: var(--surface-secondary);
  --accent-foreground: var(--text-primary);
  --destructive: var(--color-error);
  --destructive-foreground: var(--text-inverse);
  --border: var(--border-primary);
  --input: var(--border-primary);
  --ring: var(--border-focus);
  --radius: var(--radius-md);
}

/* === Layer 3: Tailwind @theme — Motif tokens as utility classes === */
@theme inline {
  /* Colors: bg-primary-500, text-primary-500, etc. */
  --color-primary-50: var(--color-primary-50);
  /* ... all --color-* tokens stay as-is (already in color namespace) ... */

  /* Surface/text/border colors: re-namespaced to avoid Tailwind collision */
  /* --surface-primary -> --color-surface-primary -> utility: bg-surface-primary */
  --color-surface-primary: var(--surface-primary);
  --color-surface-secondary: var(--surface-secondary);
  --color-surface-tertiary: var(--surface-tertiary);
  --color-surface-elevated: var(--surface-elevated);
  /* --text-primary (color) -> --color-text-primary -> utility: text-text-primary */
  --color-text-primary: var(--text-primary);
  --color-text-secondary: var(--text-secondary);
  --color-text-tertiary: var(--text-tertiary);
  --color-text-inverse: var(--text-inverse);
  --color-text-link: var(--text-link);
  /* --border-* -> --color-border-* */
  --color-border-primary: var(--border-primary);
  --color-border-focus: var(--border-focus);
  /* Semantic colors */
  --color-success: var(--color-success);
  --color-error: var(--color-error);
  --color-warning: var(--color-warning);
  --color-info: var(--color-info);

  /* Spacing: use Tailwind default --spacing multiplier pattern */
  /* Per research open question 2: override default --spacing base to match Motif's 4px */
  --spacing: 0.25rem;

  /* Fonts (CSS variable references -- actual values come from next/font at runtime) */
  --font-display: var(--font-display);
  --font-body: var(--font-body);
  --font-mono: var(--font-mono);

  /* Radii */
  --radius-sm: var(--radius-sm);
  --radius-md: var(--radius-md);
  --radius-lg: var(--radius-lg);
  --radius-xl: var(--radius-xl);
  --radius-full: var(--radius-full);

  /* Shadows */
  --shadow-sm: var(--shadow-sm);
  --shadow-md: var(--shadow-md);
  --shadow-lg: var(--shadow-lg);
}
```

**Critical namespace rules:**
1. Tokens already prefixed `--color-*` go into @theme as `--color-*` (no change needed)
2. Tokens prefixed `--surface-*`, `--text-*` (color tokens, NOT font sizes), `--border-*` get remapped to `--color-surface-*`, `--color-text-*`, `--color-border-*` in @theme
3. Tokens prefixed `--text-*` where the suffix is a size indicator (xs, sm, base, lg, xl, 2xl, 3xl, 4xl) are TYPOGRAPHY tokens -- include in :root but do NOT put in @theme (Tailwind already has --text-* for font sizes, and these values match)
4. Font family tokens (`--font-display`, `--font-body`, `--font-mono`) are EXCLUDED from Layer 1 :root block entirely (next/font provides them at runtime). They ARE included in @theme as var references so Tailwind utilities work.
5. Use `--spacing: 0.25rem` in @theme to set Tailwind's base spacing multiplier to match Motif's 4px base. This means `p-4` = 1rem = 16px = Motif's `--space-4` naturally.

**Implementation approach:**
- Use `parseTokensCSS()` to get all tokens from input tokens.css
- Use `categorizeTokens()` to group them by category
- Generate Layer 1 by iterating categories, writing CSS custom properties (skip font-family tokens)
- Generate Layer 2 with hardcoded shadcn mapping (the mapping is stable -- shadcn variable names are a fixed contract)
- Generate Layer 3 by iterating categories and applying namespace rules above
- Write result to output path

**Edge cases:**
- If tokens.css has no `--color-error` token, the shadcn `--destructive` mapping should use a fallback: `var(--color-error, #ef4444)`
- If tokens.css has no `--surface-tertiary`, shadcn `--secondary` should fallback: `var(--surface-tertiary, var(--surface-secondary))`
- If tokens.css is empty or unparseable, exit with code 1 and error message
