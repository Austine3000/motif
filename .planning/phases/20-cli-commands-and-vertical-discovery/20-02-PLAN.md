    Create bin/commands/update.js following the established command module pattern.

    The update command must:
    1. Parse flags: --help/-h (boolean), --force/-f (boolean, default false). Use parseArgs with strict: true.
    2. Find project root via findProjectRoot(process.cwd()). Error and exit 1 if not found.
    3. Read manifest via readManifest(projectRoot). If null, error "No Motif installation found" and exit 1.
    4. Get global package version via getPackageVersion().
    5. Compare versions using compareVersions(manifest.version, packageVersion):
       - If equal (returns 0): print "Already up to date (vX.Y.Z)" in green and exit 0.

       - If installed is OLDER or --force is set: proceed with update.
    6. To perform the actual update: require('./init.js').run(['--force']). The init command with --force already handles file copying, backup of modified files, manifest regeneration, and config injection. This avoids duplicating 700+ lines of install logic.
    7. Print update summary: "Updated Motif: {oldVersion} -> {newVersion}" in cyan before calling init.run.

    Imports: node:util (parseArgs, styleText), ../lib/find-root.js, ../lib/manifest.js, ./init.js (for the actual sync).

<task type="auto">
  <name>Task 2: Implement motif doctor command</name>
  <files>bin/commands/doctor.js</files>
  <action>
    Create bin/commands/doctor.js following the established command module pattern.

    The doctor command performs 3 categories of checks:

    **Category 1: File Integrity**
    - Read manifest via readManifest(projectRoot).
    - For each file in manifest.files: check existence (fs.existsSync). If missing, record FAIL.
    - For existing files: hash with hashFile() and compare to manifest hash. If different, record WARN (modified by user -- not an error, just informational). If same, record PASS.

    **Category 2: Hook Configuration**
    - Read CLAUDE.md from projectRoot. Check for MOTIF-START and MOTIF-END sentinel markers. If both present, PASS. If missing, FAIL.
    - Read .claude/settings.json from projectRoot. Check for:
      a. hooks.PostToolUse array exists and contains at least one entry with "motif" in the command string. If yes, PASS. If no, FAIL.
      b. hooks.SessionStart array exists and contains entry with "motif-session-start" in command. If yes, PASS. If no, FAIL.
      c. statusLine exists and contains "motif-context-monitor" in command. If yes, PASS. If no, FAIL.
    - If settings.json doesn't exist or is invalid JSON, record all hook checks as FAIL.

    **Category 3: Version Consistency**
    - Compare manifest.version with getPackageVersion().
    - If equal, PASS ("Versions match").
    - If manifest is newer, WARN ("Project version newer than global package").
    - If manifest is older, WARN ("Update available: vX.Y.Z").

    **Output format:**
    - Header: "Motif Doctor" (bold)
    - Group results by category with category headers.
    - Use symbols: checkmark (PASS), warning triangle (WARN), cross (FAIL) -- use simple ASCII: [OK], [!!], [XX].
    - Color: green for OK, yellow for WARN, red for FAIL.
    - Summary line at end: "X passed, Y warnings, Z failed" with overall color (green if 0 failures, yellow if warnings only, red if any failures).
    - Exit code: 0 if no failures, 1 if any failures.

    Imports: node:fs, node:path, node:util (parseArgs, styleText), ../lib/find-root.js, ../lib/manifest.js (readManifest, getPackageVersion, compareVersions, hashFile).
  </action>
  <verify>
    Run: node -e "require('./bin/commands/doctor.js')" (should load without error)
    Run: node -e "require('./bin/commands/doctor.js').run(['--help'])" (should print help)
    Run from project root: node bin/commands/doctor.js (should run all checks and print report)
  </verify>
  <done>doctor.js exports run(args), checks file integrity (manifest files present + hash comparison), hook configuration (CLAUDE.md sentinels + settings.json hooks), and version consistency (global vs project). Prints categorized report with pass/warn/fail counts.</done>
</task>
