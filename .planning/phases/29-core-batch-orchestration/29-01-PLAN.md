Add the `batch-update-screens` command to motif-state.js — the atomic state update primitive that the batch orchestrator will call after each wave to update all screen statuses in a single read-modify-write cycle.

Output: Extended motif-state.js with new `batch-update-screens` command.

7. Perform a SINGLE atomic write using existing `serializeFrontmatter()` and `atomicWrite()`.
8. Write `{"ok": true, "updated": N}` to stdout where N is `updates.length`.
