  <action>
Create `.claude/get-motif/scripts/token-transformer.js` -- a pure Node.js script (zero dependencies) that reads tokens.css and produces platform-specific TypeScript token files.

**CLI interface:**
```
node scripts/token-transformer.js [tokens-css-path] [--platform <id>] [--output-dir <dir>]
```
- `tokens-css-path`: defaults to `.planning/design/system/tokens.css`
- `--platform`: reads from STATE.md if not provided (via `node scripts/motif-state.js read`)
- `--output-dir`: defaults to same directory as tokens.css

**Core functions (implement in this order):**

1. **`parseTokensCSS(cssContent)`** -- Extract all CSS custom properties from `:root {}` block.
   - Use regex: `/--([a-zA-Z0-9_-]+)\s*:\s*([^;]+);/g`
   - Return object: `{ name: value }` pairs
   - Only parse properties inside `:root { }` blocks (ignore media queries, .dark class, etc.)

2. **`categorizeTokens(tokens)`** -- Sort tokens into categories using Motif's naming conventions.
   - CRITICAL naming collision handling for `--text-*` tokens:
     - `--text-primary`, `--text-secondary`, `--text-tertiary`, `--text-inverse`, `--text-link` are **colors** (semantic text color names)
     - `--text-xs`, `--text-sm`, `--text-base`, `--text-lg`, `--text-xl`, `--text-2xl`, `--text-3xl`, `--text-4xl` are **typography** (size suffixes: xs/sm/base/lg/xl/2xl/3xl/4xl)
     - Implementation: check suffix first. If suffix matches `/^(xs|sm|base|lg|xl|2xl|3xl|4xl)$/`, it is typography. Otherwise, `--text-*` tokens are colors.
   - Categories: colors, typography, spacing, radii, shadows, transitions, zIndex, icons, other
   - Color prefixes: `color-`, `surface-`, `border-` (and `text-` when not a size suffix)
   - Typography prefixes: `font-`, `leading-`, `weight-` (and `text-` when a size suffix)
   - Spacing: `space-`
   - Radii: `radius-`
   - Shadows: `shadow-`
   - Transitions: `ease-`, `duration-`
   - Z-index: `z-`
   - Icons: `icon-`

3. **`kebabToCamel(str)`** -- Convert `primary-500` to `primary500`, `font-display` to `fontDisplay`.

4. **`stripPrefix(name, category)`** -- Remove category prefix from token name for cleaner keys (e.g., `color-primary-500` -> `primary-500`, `space-4` -> `4`).

5. **`generateWebTS(categories, hash)`** -- Emit tokens.ts for React web platforms.
   - Header: `// Auto-generated from tokens.css by Motif. Do not edit manually.` and `// Source hash: {hash}`
   - Export each category as a named const with `as const`
   - Values are all strings (CSS values used directly in inline styles or as CSS var references)
   - Final aggregate export: `export const tokens = { colors, typography, spacing, ... } as const;`
   - Final type export: `export type Tokens = typeof tokens;`

6. **`convertToNativeValue(value, tokenName)`** -- Convert CSS values to React Native-compatible values.
   - `Xrem` -> `X * 16` (number)
   - `Xpx` -> `X` (number)
   - `Xem` -> `X * 16` (number)
   - Bare numbers (e.g., weights `400`, z-index `100`) -> number
   - Colors (`#hex`, `rgb()`, `hsl()`) -> string pass-through
   - Font families: strip fallbacks, keep only primary font name, remove quotes
   - `cubic-bezier(...)` -> string pass-through
   - Duration values (`150ms`, `0.4s`) -> string pass-through (RN Animated uses these as strings)

7. **`parseShadowForNative(shadowValue)`** -- Decompose CSS shadow into RN shadow properties.
   - Parse: `X Y blur spread color` (spread is optional)
   - Handle multi-shadow values (split on `, ` that is NOT inside parentheses)
   - For each shadow, emit: `{ shadowColor, shadowOffset: { width, height }, shadowOpacity, shadowRadius }`
   - Add `elevation` estimate: `Math.ceil(blur / 2)` capped at 24
   - If shadow is `none`, return null
   - Use FIRST shadow value if multiple shadows exist (RN only supports one shadow)

8. **`generateNativeTS(categories, hash)`** -- Emit tokens.native.ts for React Native.
   - Same header and structure as web
   - All values go through `convertToNativeValue()`
   - Shadow category uses `parseShadowForNative()` to emit structured objects instead of strings
   - Transitions category: emit as-is (strings) -- RN Animated handles its own timing
   - Export as `theme` instead of `tokens` (RN convention): `export const theme = { ... } as const;`

9. **`generateHash(content)`** -- SHA-256 hash of tokens.css content (first 12 chars). Use `node:crypto`.

**CLI execution flow:**
1. Read tokens.css from path
2. Determine platform: from `--platform` flag, or by running `node scripts/motif-state.js read` and extracting `.platform`
3. Read framework-registry.json to get `tokens.formats` for the platform
4. Parse tokens, categorize, generate hash
5. For each format in `tokens.formats`:
   - `ts` -> write `tokens.ts` using `generateWebTS()`
   - `native-ts` -> write `tokens.native.ts` using `generateNativeTS()`
   - `css` -> skip (already exists as source)
6. Print summary: "Generated: tokens.ts (N exports)" or similar
7. Exit 0 on success, exit 1 on error with message to stderr

**Error handling:**
- If tokens.css not found: stderr message, exit 1
- If platform unknown: stderr warning, generate both formats as fallback
- If STATE.md missing: stderr warning, generate both formats as fallback
