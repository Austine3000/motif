Create `.claude/get-motif/references/verticals/devtools.md` following the EXACT section heading structure of fintech.md. Use 18-RESEARCH.md "DevTools Vertical" section for domain-specific content.

CRITICAL DIFFERENTIATION FROM SAAS: DevTools and SaaS share audience (technical users) but DevTools MUST emphasize:
- Code/terminal-centric components (CodeBlock, LogViewer, StatusPipeline) vs SaaS data tables/command palettes
- Dark-mode-first design (Palette B is dark-mode-native with surface-primary #0A0A0B)
- Monospace-heavy typography (JetBrains Mono is primary, not just for code snippets)
- Build pipeline patterns, log viewing, API documentation patterns
- Dense, information-rich layouts vs SaaS collaborative workspace feel

Required sections (in this exact order with these exact headings):
1. `# DevTools Design Intelligence`
2. `## Core Design Principle` -- "Speed is the product." Bold one-liner + expansion about keystrokes saved, cognitive load reduction
3. `## Navigation Patterns` with `### Standard Models` and `### Vertical-Specific Rules`
   - Desktop-first (mobile is read-only monitoring at best)
   - Dense left sidebar with icon-only collapse (56px)
   - Command palette (Cmd+K) as PRIMARY navigation
   - Terminal/console panel at bottom, resizable
4. `## Color System` with:
   - `### Palette A: Deep Navy-Slate (Code Editor)` -- primary-500 around #6366F1, full scale, light+dark
   - `### Palette B: Dark Mode Native (Developer)` -- surface-primary #0A0A0B, primary-500 #22D3EE, full scale
   - `### Semantic Colors` -- Success=build passed, Error=build failed, Warning=deprecation/rate limit, Info=new release
   - `### Color Anti-Patterns` -- e.g., "Never use low-contrast syntax highlighting"
5. `## Typography` with:
   - `### Pairing A: Space Grotesk + IBM Plex Sans` -- engineering precision
   - `### Pairing B: JetBrains Mono + IBM Plex Sans` -- monospace-first, code-native
   - `### Data & Mono` -- CRITICAL section: JetBrains Mono or Fira Code for ALL code, logs, terminal, API responses. Monospace is not secondary here -- it is dominant.
   - `### Type Scale`, `### Typography Rules`, `### Typography Anti-Patterns`
6. `## Spacing & Density` with `### Recommended Density: Dense` and `### Concrete Values`
   - Dense is correct for DevTools (vs Comfortable for social/education)
7. `## Component Specifications` -- 3 XML components:
   - CodeBlock (syntax-highlighted code, line numbers, copy button, language badge, expand/collapse)
   - StatusPipeline (horizontal pipeline stages build/test/deploy with pass/fail/running)
   - LogViewer (scrollable log output, severity coloring, timestamp, filter by level, search)
8. `## Interaction Patterns` with `### Core Flows`, `### States` (devtools-specific), `### Motion`
   - Motion should be MINIMAL -- developers find animations distracting
9. `## Accessibility Specifics` -- keyboard-first (developers expect full keyboard nav), high contrast for code
10. `## Border Radius` -- minimal, sharp (2-6px, matching code editors)
11. `## Shadow Style` -- subtle or none (flat, code-editor aesthetic)
12. `## Icon Vocabulary` with HTML verification comment, 4 category tables:
    - Navigation (5), Developer & Infrastructure (6-8), Status & Feedback (4-5), Actions (5-6)
    - Primary library: Lucide. Same 4-column format.
    - `<!-- Icon names verified against: Lucide v0.400+, Phosphor Icons v2.1+, Material Symbols, Tabler Icons v3.0+ -->`
13. `## DevTools-Specific Additions` -- 4-7 bullets emphasizing what makes this NOT SaaS
