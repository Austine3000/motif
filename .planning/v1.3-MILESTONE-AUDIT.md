## Root Cause

Phase 17 (context resilience) and Phase 18 (new verticals) modified files in the **installed** `.claude/get-motif/` directory but did NOT propagate those changes to **package source** directories (`runtimes/claude-code/hooks/`, `scripts/`, `core/references/`, `runtimes/claude-code/CLAUDE-MD-SNIPPET.md`). The `motif init` command copies FROM package source TO project — without syncing, new installs miss Phase 17/18 artifacts entirely.

Additionally, `init.js injectHookSettings()` registers PostToolUse hooks and statusLine, but does NOT register SessionStart hooks (only manually edited into local `.claude/settings.json`).

**Phase 21 (Package Source Sync)** was added as gap closure to address all of these issues. It has research completed and 2 plans defined but is NOT STARTED (0/2 plans executed).
